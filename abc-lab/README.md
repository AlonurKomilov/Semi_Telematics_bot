# abc-lab — the abc-skills family workspace

Every kept tool, rig or script created by the abc-skills audit family
lives HERE, one self-contained folder per harness — never scattered
through the project's own tree (the ux-interaction-performance-audit
skill's workspace-isolation rule).

Current harnesses:
- `perf-rig/` — the seeded Dispatch-KPI board for performance A/B runs.

**Deleting this entire folder (`rm -rf abc-lab`) removes every trace of
the family's tooling from the project, always.**  Nothing else in the
project depends on it.
